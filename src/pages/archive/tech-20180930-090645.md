discord.pyを使ってDiscord Botを開発しているときに発生した「'Client' object has no attribute 'send\_message'」エラーの解決法です。

### 環境

- AWS EC2
- Python3.6
- [Rapptz/discord.py(rewrite版)](https://github.com/Rapptz/discord.py/)

### 解決法

原因はrewrite版を使っていることで、メッセージ送信の記述が異なるためでした。

#### 元の記述

```
await client.send_message(message.channel, "メッセージ")
```

#### 修正後の記述

```
await message.channel.send("メッセージ")
```
